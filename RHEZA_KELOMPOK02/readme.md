# 📘 Sistem Informasi Akademik Sekolah – SMK Perguruan Cikini

## 🧭 Tujuan Proyek

Proyek ini bertujuan untuk merancang dan membangun sistem informasi akademik sekolah berbasis web untuk **SMK Perguruan Cikini** dengan fokus pada pengembangan **front-end** sesuai standar **SKKNI**.

---

## ⚙️ Spesifikasi Fungsionalitas

- **Loading Page**: Halaman animasi loading menggunakan CSS.
- **Login Page**: Form autentikasi pengguna dengan validasi input.
- **Home Page**: Ringkasan notifikasi, info akademik, dan navigasi fitur.
- **Jadwal Pembelajaran**: Tabel jadwal siswa/guru.
- **Rapor Bayangan**: Tabel nilai siswa dengan tampilan yang rapi.
- **Profile Pribadi**: Menampilkan informasi pribadi pengguna.
- **Profile Sekolah**: Info umum sekolah dan jurusan.
- **Pengaturan**: Form preferensi tema, ubah password, dll.
